# 重世 ReWorld

## 简述

`ReWorld`是一款 `肉鸽` + `RPG` + `2D平面游戏` + `冒险` + `建造` + `生产` + `NPC好感度` + ... 兼收并蓄的游戏，当然不是抄袭，因为你很难找到多个相似的高的游戏，如果真的有，纯属雷同。

### 游戏核心

#### 核心矛盾

> 击败Boss会解放魔的力量，但不击败就无法获得神的力量来对抗循环。

#### 游戏内容

> 白天是改变一切的机会

#### 关键设计

> 白天（白昼期）是唯一能动的时间。黑夜（0点）不是休息，是强制终结。玩家对抗的不是敌人，是时间本身。

#### 游戏游玩逻辑

```
[0点] 游戏开始的时间
[0点-->第二天0点] 游戏进行时间（类似RPG玩法，有肉鸽般丰富的战斗系统
	└ 可以建筑，生产，与npc交流
	└ 战斗获得道具，装备
	└ 击败Boss获得锁区道具和神能力（其中）
[第二天0点]
	└ 重置世界（地图重新生成，npc记忆清空，建筑清空 | 除锁区内内容：npc记忆，建筑，地图区域）
	└ 将玩家除特殊物品以外的物品全部转化为点数
[时间暂停]
	└ 传送玩家至"小黑屋"点数商店

*点数：
| 修改玩家属性
| 购买装备
*锁区道具 = 救世符石碎片
*"小黑屋" = 救世主，魔神的战场中心的一个屋子
```

#### **神魔人之力的三角关系**

- **神之力**：光明但受限时段，代表"规则内的力量"
- **魔之力**：强大但透支未来，代表"借来的时间"
- **人之力**：符石诗歌的状态变化，记录玩家的**道德轨迹**

## 游戏内容

### 一、时间系统：0点的暴政

#### **[0:00 → 24:00] 白昼期 **

|     阶段     | 时间流速            | 世界状态             | 玩家行为                |
| :----------: | ------------------- | -------------------- | ----------------------- |
|  黎明 [0-6]  | x2倍速              | 怪物虚弱，资源丰沛   | 采集、建造基础          |
| 正午 [6-12]  | 正常                | 平衡状态             | 探索、战斗、	NPC交互 |
| 黄昏 [12-18] | x0.5倍速            | 怪物躁动，Boss活跃   | 决战、锁区、收尾        |
| 夜幕 [18-24] | x0.25倍速（紧迫感） | 魔之力渗透，世界扭曲 | 逃亡、巩固、告别        |

**时间可视化**：屏幕边缘有**光弧**，从左侧（黎明）流向右侧（午夜）。光弧颜色从金→白→橙→紫→黑渐变。

**关键机制**：玩家可消耗**时露**（神之力资源）短暂**暂停个人时间**（子弹时间），但世界时间仍在流动。

#### [24:00] 归零时刻 

  >世界**褪色为黑白**，所有动作冻结
  >
  >玩家无法移动，只能**观看**自己这一天的成果被"擦除"
  >
  >未被锁区的建筑、NPC记忆、地图区域**如沙般流散**
  >
  >背包物品（除特殊物品）**化为光点**，汇聚为**点数**

##### **情感设计**

- 归零不是黑屏加载，是**漫长的30秒动画**——你看着刚建好的房屋崩塌，看着NPC眼中的认识变为陌生，看着战斗获得的装备消散。你可以**快进**，但第一次不能跳过。

- 但是后期随着锁区增加，动画中保留的内容增多，**褪色与抵抗的视觉对比**成为正反馈

- 后期解锁"诗人陪伴"选项，她在褪色中朗诵，减轻压抑感

#### [小黑屋] 间隙期

**实体设定**：救世主与魔神战场的中心，一座**没有门窗的石屋**。屋内只有：

- 一面**碎镜**（映出你这一天的剪影）
- 一张**石桌**（点数商店界面）
- 地上**刻满诗歌的凹槽**（救世符石碎片插入处）

**时间状态**：真正的**时间暂停**。屋外是永恒的午夜，星光与黑暗交织成漩涡。

**玩家行为**：

```
1. 查看碎镜 → 回顾这一天的高光/遗憾（自动生成的诗歌）
2. 点数消费 → 强化自身/购买装备/解锁永久建筑图纸
3. 插入符石碎片 → 选择下一天要"锁区"保留的内容
4. 静坐 → 可选择跳过间隙，直接开始下一天（但失去思考时间）
```

### 二、锁区系统：救世符石的碎片

#### 符石碎片获取

| 来源     | 碎片类型                   | 锁区效果                      |
| -------- | -------------------------- | ----------------------------- |
| 击败Boss | **大碎片**（雕刻完整诗句） | 锁区一个**区域**（地图板块）  |
| 探索隐藏 | **中碎片**（残句）         | 锁区一个**建筑**或**NPC关系** |
| 日常采集 | **小碎片**（单字）         | 锁区一个**物品栏格子**的内容  |

**碎片实体**：不是道具，是**发光的文字**——漂浮在空中，触碰时朗读出诗句（语音或文字浮现）

#### 锁区机制

```
白昼期：
    获得碎片 → 选择"铭记"（立即消耗，标记要保留的对象）
    被标记对象周围出现 淡金色光晕
    
归零时刻：
    被标记对象 抵抗褪色，但光晕会 消耗碎片能量
    若碎片能量不足 → 部分保留（建筑缺一角，NPC记得你但名字模糊）
    
间隙期：
    可调整下一天的锁区策略
    但已使用的碎片 永久消失（诗歌被世界吸收，成为环境叙事）
```

### 三、点数系统：白天的遗产

#### 转化规则

| 物品类型   | 转化比例 | 备注                                               |
| ---------- | -------- | -------------------------------------------------- |
| 普通材料   | 1:1      | 木材、矿石等                                       |
| 精良装备   | 1:3      | 需使用过才有价值                                   |
| Boss掉落   | 1:10     | 但可选择不转化，保留为"特殊物品"（占用极稀有栏位） |
| NPC赠礼    | 1:5      | 但转化时NPC会"心痛"（下一天初始好感-10%）          |
| 未使用碎片 | 1:20     | 鼓励使用，不囤积                                   |

#### 点数消费（小黑屋商店）

| 类别     | 内容                                   | 成本   | 永久/临时    |
| -------- | -------------------------------------- | ------ | ------------ |
| **属性** | 生命/攻击/防御/感知                    | 递增   | 永久         |
| **图纸** | 建筑蓝图（解锁后白昼期可建）           | 一次性 | 永久         |
| **装备** | 基础武器/防具（下一天开局携带）        | 中等   | 临时（一天） |
| **记忆** | 解锁NPC背景故事（不影响战力，纯叙事）  | 高     | 永久         |
| **诗歌** | 购买救世符石上的诗句（解锁新碎片类型） | 极高   | 永久         |

**关键设计**：点数不能买**时间**。你无法购买"延长白昼"，只能购买"在有限时间内做得更多"。

### 四、神魔人之力：万物之始

#### 神之力：星月器官

##### 获取方式

击败Boss后，从Boss体内提取。Boss是**心结的具象化**，击败它=直面自己的阴暗。

| 器官         | 实体形态                 | 能力               | 白昼期限制                                 |
| ------------ | ------------------------ | ------------------ | ------------------------------------------ |
| **黎明之瞳** | 银白眼珠，瞳孔是初升太阳 | 标记敌人，暴露弱点 | 仅在黎明时段（0-6）充能，其他时段衰减      |
| **正午之刃** | 炽白热刃，边缘有光晕     | 次元斩，切割空间   | 正午（6-12）伤害×2，夜幕（18-24）无法使用  |
| **黄昏之心** | 橙红球体，内部有落日     | 时停领域           | 黄昏（12-18）时停时长最长，黎明最短        |
| **星尘之肺** | 深蓝晶体，呼吸时散发星点 | 短距传送           | 夜幕（18-24）无消耗，正午消耗×3            |
| **月轮之胃** | 银白囊袋，内部有潮汐     | 空间储存           | 满月夜（随机日期）容量无限，新月夜无法打开 |

##### **核心机制**

神之力**依赖白昼时段**。它们是**光的器官**，在黑暗中沉睡。



#### 魔之力：黑暗的侵蚀

##### 获取方式

不归零时获得。魔之力在**夜幕时段（18-24）**主动渗透，玩家可选择**接受**或**抵抗**。

| 层级     | 实体表现                   | 能力                 | 代价（下一天）                         |
| -------- | -------------------------- | -------------------- | -------------------------------------- |
| **墨滴** | 皮肤出现黑色水滴纹身       | 夜幕时段攻击附带吸血 | 下一天黎明，生命上限-5%                |
| **裂帛** | 衣物出现无法修补的裂口     | 可撕裂空间短距传送   | 下一天正午，随机丢失一件装备           |
| **蛀空** | 武器内部出现空洞，外观完好 | 攻击无视防御         | 下一天黄昏，武器碎裂                   |
| **归墟** | 瞳孔变为纯黑，无反光       | 夜幕时段无敌         | 下一天归零时，**额外失去一个锁区碎片** |

##### **核心机制**

魔之力**即时强大**，但**透支下一天**。它是**借来的时间**，总要偿还。



#### 人之力：救世符石

##### 符石本体

玩家开局持有的**完整石盘**，雕刻满诗歌。但随着循环：

- 每次使用锁区 → 对应诗句**发光后暗淡**（诗歌被"实现"）
- 每次使用魔之力 → 对应诗句**被墨迹污染**（诗歌被"扭曲"）
- 每次归零时未使用 → 对应诗句**风化剥落**（诗歌被"遗忘"）

##### **最终状态**

- 全部发光 → 神之结局（秩序永恒）
- 全部污染 → 魔之结局（混沌解放）
- 全部剥落 → 虚无结局（无诗可念）
- 混合状态 → 人之结局（诗歌重组，新故事诞生）

##### 诗歌功能（符石碎片）

每片碎片上的诗句，是**可朗读的咒语**：

| 诗句类型   | 效果                   | 朗读时机           |
| ---------- | ---------------------- | ------------------ |
| **铭记诗** | 强化锁区效果           | 白昼期，标记对象时 |
| **忘却诗** | 清除魔之侵蚀一层       | 夜幕期，抵抗渗透时 |
| **祈愿诗** | 临时提升属性           | 战斗前             |
| **悼亡诗** | 复活一次（一天限一次） | 死亡瞬间自动朗读   |
| **无名诗** | 未知效果（随机）       | 任何时刻，风险自负 |

##### **朗读机制**

屏幕上浮现几个**被打乱的词**，玩家按**正确顺序**输入，输入越快，效果越强——但输错会**反噬**（碎片碎裂，诗歌永久丢失）。

### 五、NPC好感度：被时间遗忘的人

#### NPC设计

他们不是程序，是**被困在循环中的意识**。他们知道归零，但**无法保留记忆**——除非被锁区。

| NPC           | 身份         | 白昼期行为                 | 被锁区后的变化                                     |
| ------------- | ------------ | -------------------------- | -------------------------------------------------- |
| **守夜人·弦** | 神之祭司后裔 | 黎明时在月池祈祷           | 保留祈祷习惯，但开始**质疑**月池的意义             |
| **浸墨者·渊** | 魔之学者     | 夜幕时在裂缝边缘记录       | 保留记录习惯，但记录内容变为**预言**               |
| **忆者·无**   | 无面记录员   | 全天游荡，重复同一天的动作 | 保留游荡，但开始**寻找**自己的脸                   |
| **锁匠·钥**   | 石之工匠     | 黄昏时检查锁区石裂纹       | 保留检查，但开始**修补**而非只是观察               |
| **诗人·吟**   | 救世主的同族 | 午夜前朗诵诗歌             | 保留朗诵，但诗歌内容**每天变化**（受玩家行为影响） |

##### **关键事件**

`诗人·吟`是唯一**天生记得**的NPC。她的诗歌每天变化，是因为她在**记录玩家的故事**。当玩家锁区她时，她会**哭泣**——不是因为痛苦，是因为她终于**被看见了**。

#### 好感度机制

```
白昼期交互：
    ├── 对话（每次限3次，选择影响倾向）
    ├── 共同行动（探索/战斗/建造）
    ├── 赠予（物品/诗歌/时间——陪伴即赠予时间）
    └── 锁区承诺（"我会记住你"——消耗碎片，建立羁绊）

归零时刻：
    未锁区NPC → 眼神从认识变为陌生，嘴唇翕动但未出声（可能是"再见"）
    已锁区NPC → 抵抗褪色，但会 痛苦（他们记得被忘记的恐惧）

间隙期：
    碎镜中可查看NPC的"如果"——未被锁区的他们，下一天会怎样
    可选择用点数购买"记忆保险"——下一天该NPC初始好感+20%
```

### 六、建造+生产：白天的创造

#### 建筑系统

| 建筑     | 功能                           | 材料      | 锁区价值             |
| -------- | ------------------------------ | --------- | -------------------- |
| **月池** | 神之力恢复                     | 月华+石材 | 高（功能核心）       |
| **墨井** | 魔之力排放/储存                | 暗沼+木材 | 中（风险与收益并存） |
| **诗碑** | 记录当天诗歌，下一天可读       | 石材+碎片 | 低（纯叙事）         |
| **锁桩** | 标记区域，便于锁区             | 金属+实底 | 中（策略性）         |
| **时晷** | 显示精确时间，预警归零         | 星屑+晶体 | 高（生存必需）       |
| **眠床** | 短暂跳过时间（风险：错过事件） | 木材+织物 | 低（功能性）         |

#### 生产循环

```
黎明：采集基础资源（月华丰沛，怪物虚弱）
    ↓
正午：加工/建造/交互（平衡期，效率最高）
    ↓
黄昏：决战/锁区/收尾（Boss活跃，高风险高回报）
    ↓
夜幕：选择——抵抗魔渗透，或接受力量透支下一天
```

### 七、Boss设计：心结的24小时

每个Boss代表一种**被时间困住的情绪**，在特定时段最活跃。

击败Boss后Boss领域

#### 「迟暮·未寄的信」

##### **背景**

> 一个永远在等待回信的人，在黄昏时分化为Boss。

##### **实体形态**
> 主体：由无数**信封**拼凑的人形，信封上写满未寄出的文字
> 左手：握着**燃尽的蜡烛**（光已耗尽）
> 右手：握着**未封口的信**（内容每天都在变，是玩家这一天的遗憾）
> 脚下：一圈**日晷刻度**，指针逆向转动

##### **时段特性**
> 黎明：虚弱，信封散落，可读取内容（叙事）
> 正午：均衡，信封飞舞形成护盾
> 黄昏：**狂暴**，日晷指针加速，时间流速紊乱（玩家技能CD随机变化）
> 夜幕：凝固，Boss停止动作，但玩家攻击会被"延迟"到第二天生效

##### **击败后**
> 提取**黄昏之心**（神之器官）
> 释放**墨滴级侵蚀**（区域出现黑色水洼）
> 获得**未寄出的信**（特殊物品，可阅读，可转化为点数，可选择**锁区保留**——下一天该Boss不会出现，但会留下一个**空座位**）

### 八、真结局：0点之后

#### **神之永续**

**条件**：全部诗歌发光，无魔侵蚀

```
24:00到来，但世界 没有褪色 。
弦说："你成为了新的太阳。
"你坐在月池中，身体逐渐发光，但无法移动——永恒的白天，永恒的静止。
```

#### **魔之解放**

**条件**：全部诗歌污染，无锁区

```
24:00到来，世界加速褪色，但你在褪色中自由移动。
渊说："终于，不用再等了。
"你走进裂缝，身体消散，但无处不在——永恒的午夜，永恒的流动。
```

#### **人之诗歌**

**条件**：诗歌混合状态，诗人·吟被锁区且好感满

```
24:00到来，诗人开始朗诵新的诗歌——不是救世主的诗，是你的诗。
世界一半褪色，一半保留，但褪色的部分留下轮廓——像未完成的手稿。
吟说："明天，我们一起写下去。"
```

#### **0点之后**（隐藏）

**条件**：：连续100天，每天锁区一个**不同的NPC**，但从不锁区自己

```
第100天的24:00，你没有进入小黑屋。
你站在褪色中的世界，看着所有被记住的NPC同时看向你。
他们说："该我们记住你了。
"你化为新的救世符*，雕刻满100首诗，等待下一个玩家。
```

## 核心体验总结

> **白天是改变一切的机会**——但白天会结束。
> **0点是必然的终结**——但终结后有间隙。
> **间隙是反思的空间**——但反思不能阻止下一个0点。
> **唯一真实的，是你在白天做出的选择，和你在间隙中记住的感受。**

玩家最终会发现：锁区不是对抗归零，是**选择记住什么**。点数不是变强，是**选择如何面对下一天**。诗歌不是力量，是**证明你来过**。

**最后一个设计**：当玩家通关"人之诗歌"结局后，主界面会出现**"继续写"**选项。不是新游戏+，是**新的0:00**——但诗人·吟会在黎明时说一句："欢迎回来，昨天的你。"
